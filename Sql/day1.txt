Type of Comamnds:
----------------
1. DDL - Data definition language
2. DML - Data manipulation language
3. DRL - Data retrieval language
4. DTL - Data transaction language
5. DCL - Data control language

DDL - Data definition language:
------------------------------
As per the requirements if you want to do any kind operations on structure of the Databse objects then we can go for DDL commands

1. Define/Create the structure of the table - CREATE
2. Modify the structure of the table - ALTER
3. Remove the structure of the table - DROP

DML - Data manipulation language:
---------------------------------
As per the requirements if you want to do any kind operations on DATA then we can go for DML commands

1. Load/maintain/insert the data - INSERT
2. Modifying the data - UPDATE
3. Deleting the data - DELETE

Difference between ALTER AND UPDATE -- 
		alter - modifiction of your table structure (meatadata)
		update - modification on top of your data 
		
Difference between Delete and Drop - 
		DROP - To remove the table structure we need to go for DROP
		Delete - to remove the data 
		
With out data we can able to maintain table structure --> Empty tables --> Correct 		
With out having structure we can able to maintain the data --> Wrong statemenet
